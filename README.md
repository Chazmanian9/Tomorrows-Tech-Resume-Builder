# FC Consulting Resume Builder

A free, browser-based AI resume builder with 3 professional templates. No signup, no watermark, instant PDF download.

## Features

- **3 Professional Templates**: Modern, Classic, and Creative
- **Live Preview**: See your resume update in real-time as you type
- **Instant PDF Download**: Generate and download your resume directly in the browser
- **100% Private**: All data stays in your browser — nothing is uploaded anywhere
- **No Signup Required**: Just open and start building

## Templates

- **Modern**: Two-column layout with blue accent sidebar. Great for tech and startup roles.
- **Classic**: Centered header with traditional serif font. Perfect for corporate, finance, and legal roles.
- **Creative**: Bold gradient header with colorful sections. Ideal for design, marketing, and creative roles.

## Tech Stack

- HTML/CSS/JavaScript (single file, no build step)
- pdfmake (client-side PDF generation via CDN)
- No backend, no database, no tracking

## Deployment

1. Push to GitHub
2. Connect repo to Vercel
3. Auto-deploys to `fc-resume-builder.vercel.app`
